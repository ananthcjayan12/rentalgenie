# Rental Management Images Directory

This directory contains all images used in the Rental Management application.

## 📁 Directory Structure

```
images/
├── blush_glow_logo.png      # Main logo for desk/navbar (REQUIRED)
├── banners/                 # Portal banner images
│   ├── banner1.jpg
│   ├── banner2.jpg
│   └── ...
└── categories/              # Category images
    ├── dresses.jpg
    ├── ornaments.jpg
    └── ...
```

## 🎨 Blush & Glow Logo

### Required File
**Filename**: `blush_glow_logo.png`  
**Location**: This directory (`rental_management/public/images/`)

### Logo Specifications
- **Format**: PNG (with transparency recommended)
- **Recommended size**: 200 x 60 pixels (or similar 10:3 aspect ratio)
- **Display size**: Auto-scaled to 40px height in navbar

### Installation
```bash
# Copy your logo to this directory
cp /path/to/your/blush_glow_logo.png rental_management/public/images/
```

### Where the Logo Appears
- ✅ **Desk Navbar** - Top left corner
- ✅ **Login Page** - Brand area  
- ✅ **Website Header** - Portal pages
- ✅ **Favicon** - Browser tab icon
